# Phase 4 — Branding

> Apply the LuxForge Linux identity to the system.

This phase replaces the generic LFS system identity with the LuxForge Linux brand.

---

## Targets

| File / Setting | Value |
|---|---|
| `/etc/os-release` | `NAME="LuxForge Linux"`, `VERSION_CODENAME="Aurelux"` |
| `/etc/hostname` | `luxforge` (or chosen hostname) |
| `/etc/motd` | LuxForge Linux welcome banner |
| GRUB menu title | `LuxForge Linux — Aurelux` |
| Release notes | `RELEASE_NOTES.md` in the repo |

---

## Brand reference

- **Colors:** Obsidian black · Steel gray · Electric cyan · Warm gold
- **Tone:** Minimal · Technical · Sharp
- **Logo concept:** Stylized L+X monogram or forged hexagon badge
